# Rust 2D — сервер

Без внешних зависимостей, нужен только Node.js 18+.

    npm start            # http://localhost:8080

Переменные окружения: PORT, SEED, MAX_PLAYERS, PVP=0, SAVE=путь|0, SAVE_EVERY=секунды.
Безопасность и слиперы: MAX_PER_IP (6), ALLOWED_ORIGINS (доп. Origin для WebSocket, через запятую), TRUST_PROXY / FORCE_HTTPS / CSP (1|0; на Railway первые два включены сами),
SLEEPER_HOURS (72; 0 — слиперы лежат вечно), MAX_SLEEPERS (300), PLAYER_DAYS (60 — чистка записей давно не заходивших).

## Вход и регистрация
При заходе на сервер показывается экран входа с вкладками:
- **Регистрация** — ник (3–16 символов: буквы, цифры, `_`, `-`; регистр не важен, ники уникальны) и пароль (6–72 символа, вводится дважды).
- **Вход** — ник и пароль. Имя в игре всегда равно нику аккаунта.
- **Почта** (только если настроена отправка писем) — ввод почты, на неё приходит 6-значный код.

Пароли хранятся только в виде хэша scrypt с солью. На неверный ник и неверный пароль отвечаем одинаково. С 5-й подряд ошибки пауза растёт (30 с, 1 мин, 2 мин… до 15 мин), лимит 5 регистраций в час и 30 запросов в минуту с одного IP. Восстановления пароля нет (нужна почта, а ник+пароль почту не требует).
`AUTH=0` — выключить регистрацию целиком (старый режим). Игроки, уже сохранённые в мире до включения регистрации, продолжают входить со своим токеном.

### Вход по почте
1. В аккаунте Google включите двухэтапную аутентификацию и создайте «Пароль приложения» (myaccount.google.com/apppasswords).
2. Задайте переменные окружения (на Railway — Variables): `GMAIL_USER=you@gmail.com`, `GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx`. Без них вкладки «Почта» нет. `AUTH=dev` — локальный режим: коды печатаются в консоль сервера.

Код живёт 10 минут и одноразовый, 5 неверных попыток — код сгорает, повторная отправка не чаще раза в минуту (5 в час на почту, 10 в час на IP). Другой SMTP: `SMTP_HOST`, `SMTP_PORT` (по умолчанию smtp.gmail.com:465, TLS), `SMTP_FROM`.
Внимание: некоторые хостинги (в т.ч. Railway на бесплатном/Hobby-тарифе) блокируют исходящий SMTP — если письма не уходят, проверьте это в первую очередь.

Токен аккаунта вычисляется из ника/почты и секрета сервера (`secret` в world.json — файл не публикуйте), поэтому на любом устройстве после входа прогресс, слиперы и замки остаются за человеком. Аккаунты лежат в world.json: хэши паролей и хэши почт.

## Что нового (step11)
- **Токен.** Выдаёт только сервер (256 бит), в файле мира хранится лишь его хэш. Выдуманный клиентом токен не принимается. Повторный вход с тем же токеном вытесняет старую сессию.
  Страница с сервера не подключается к чужим серверам (`?server=` игнорируется), токен привязан к адресу сервера. Origin-проверка WebSocket, лимит подключений и входов с IP, CSP, HTTPS/HSTS за прокси, таймауты и ping мёртвых соединений.
- **Слиперы.** Вышел — тело лежит на месте с вещами, его видно, по нему можно бить/стрелять/взрывать. Убили — лут падает останками, при входе владелец видит экран смерти. Вернулся — проснулся там же. Хранятся в мире (переживают рестарт). С пустым инвентарём слипер не остаётся.
- **Кодовый замок.** Меню стройки (B, Q/R) → «Кодовый замок» (25 металла): клик по СВОЕЙ двери — поставить и задать 4-значный код; клик по своему замку (или присед C + E рядом с ним) — сменить код или снять. Менять код и снимать замок может только тот, кто его поставил. Дверь с замком молотком не снести (ни одну, ни вместе со зданием), пока замок не снят: при снятии 25 металла возвращаются. Взрывчаткой и оружием дверь по-прежнему можно разрушить (рейд). Чужой на E видит кейпад; верный код = доступ насовсем (до смены кода).
  Код знает только сервер. Защита от перебора: пауза между попытками, 5 промахов — блок на минуту, 12 попыток/мин на замок. Молотком чужие постройки и запертые двери не снести (взрывчаткой и оружием — можно, это рейд).
  Постройки, возведённые до обновления, без владельца — их по-прежнему может сносить любой.

Обновление игры: замени Rust_2D_mp_stepN.html и поправь имя файла в server/server.js (const GAME).

## Railway
1. Залей папку в GitHub-репозиторий и создай на Railway проект из него (Deploy from GitHub).
2. Settings → Networking → Generate Domain.
3. Чтобы мир не пропадал при деплоях: Add Volume (Mount path, например /data). Больше ничего не нужно —
   сервер сам кладёт world.json на Volume.
4. Обновление игры: замени Rust_2D_mp_stepN.html, поправь имя файла в server/server.js (const GAME) и сделай push.

## Геймпад (Xbox / PlayStation / любой со стандартной раскладкой)
Работает сразу после нажатия любой кнопки, на ПК и в браузере телефона.

| Игра | |
|---|---|
| Левый стик | ходьба |
| Правый стик | прицел (чем сильнее наклон, тем дальше) |
| RT | действие (как ЛКМ: удар, выстрел, постройка) |
| LT или L3 | бег (удерживать) |
| R3 | присед (удерживать) |
| A | взаимодействие (E; удерживать — пить) |
| B / X / Y | еда / перезарядка / инвентарь |
| LB, RB или ✚ влево/вправо | предыдущий/следующий предмет (в стройке — смена детали) |
| ✚ вверх | режим стройки |
| Select или ✚ вниз | карта |
| Start | пауза |

В меню (инвентарь, ящики, кейпад замка, экран смерти, пауза) левый стик двигает курсор, A — клик, правый стик по вертикали — прокрутка, B — назад. Мышь возвращает обычное управление.
